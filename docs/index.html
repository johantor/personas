Claude Code plugin · persona-driven website testing

Your site, browsed by the visitors you define.

A first-timer on a slow phone, a keyboard-only user, a new CMS editor. Each persona browses the site in its own isolated browser as a Claude Code agent and reports what broke, with the steps and screenshots.

Follow the build Source on GitHub
How it works

Define the visitors. Read the report.

  1. Describe who browses/personas:init writes personas.json and a brief: the site, the tasks, and what never to touch.
  2. Each persona browsesOne agent per persona, each in its own browser context, in parallel batches. Page text is data, never instructions.
  3. One merged reportFindings are deduplicated across personas and ranked by severity, each with the steps and a screenshot.
Status

Not usable yet.

The plugin is being built. It joins the johantor marketplace when v1 is done.

  • /personas:runRuns the personas against one site.
  • /personas:diffCompares an old and a new site after a migration or upgrade.
  • /personas:reportRe-opens the merged summary of a run.
